# xqueue

Content queue, rule validator, and scheduled poster for a restaurant-operations
X account.

**Zero dependencies.** Node 20+, `node:crypto` for OAuth 1.0a, `node:test` for
the suite. Nothing to install, nothing to audit, nothing to break on a
Chromebook.

```
npm run verify     # test + validate + build. The gate.
npm run post:dry   # what would publish right now
```

## Why this exists instead of a scheduler subscription

Scheduling is the easy half. The hard half is that a labor law post published
without its disclaimer, or a build-in-public post that names a current employer,
is a career problem — and no commercial scheduler checks for either.

| | xqueue | Typefully / Hypefury / Buffer |
|---|---|---|
| Cost | $0.65/mo API | $8–$29+/mo |
| Enforces a legal disclaimer | yes, structurally | no |
| Blocks employer names | yes | no |
| Blocks unauthorized customer claims | yes | no |
| Catches near-duplicate posts | yes | no |
| Calendar UI | no | yes |

Both need X Premium ($8/mo) — posts here run 380–700 characters against a
280-character free limit.

## Commands

| | |
|---|---|
| `npm run verify` | test + validate + build. Run before every commit. |
| `npm test` | 63 tests |
| `npm run validate` | every rule against the library; exits 1 on any error |
| `npm run build` | regenerate `queue.json` from the markdown |
| `npm run stats` | pillar split, runway, cost projection |
| `npm run next` | what publishes next, rendered as it will appear |
| `npm run post:dry` | dry run |
| `npm run post` | publish anything due |

`build` flags: `--start 2026-09-07`, `--slots 14:30,22:15`,
`--days 1,2,3,4,5`, `--tz America/Chicago`.

## What the validator enforces

| Rule | Level | Why |
|---|---|---|
| Employer names | error | employment risk |
| Unauthorized customer/pilot claims | error | no authorization yet |
| Pillar B disclaimer | error | appended at render, rechecked at send |
| Length within limit | error | 280 free / 25,000 subscribed |
| Referenced figure exists | error | only when `media/` is populated |
| URL in body | warn | $0.200 vs $0.015, plus a reach penalty |
| Near-duplicate (35% trigram overlap) | warn | X prohibits "substantially similar posts" |
| Emoji / hashtags | warn | off-voice |

`post` re-runs the full validator before sending and refuses to publish if any
post has an error.

## Adding posts

Headings must match this shape:

```
**A73 · Some title** *(attach figure 7)*
```
body goes in a fenced block
```
```

Then `npm run verify`. Adding posts extends the runway automatically; the
pillar cycle holds the 40/25/20/15 split as long as you add roughly in
proportion.
